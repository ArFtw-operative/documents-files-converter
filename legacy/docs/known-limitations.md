# Known limitations and fidelity boundaries

ConvertVault is designed to reach Acrobat-class everyday editing and document-suite coverage without making false fidelity claims. The original is preserved, every PDF Studio save creates a revision, and export creates a separate validated derivative.

PDF is a final-layout format rather than a semantic authoring format. Existing text replacement is exact-search based and reconstructs the replacement in an available font. Subset fonts, outlined glyphs, unusual encodings, transparency groups, optional-content layers, XFA forms, 3D/video objects, and complex tagged-PDF structures may not be directly editable. Editing any signed PDF changes its bytes and invalidates prior cryptographic signatures; the current signature tool places a visual signature image, not a new certificate-backed digital signature. Certificate signing, preflight/fixups, automated accessibility remediation, full PDF/UA authoring, print-production separations, and collaborative cloud review are not yet implemented. These are tracked as Acrobat-parity work, not represented as complete.

No OCR system can guarantee 100% accuracy for every scan. Selectable text and structured document XML are extracted directly. Scanned pages and images use local Tesseract/OCRmyPDF when installed; accuracy depends on resolution, skew, noise, handwriting, language packs, typography, and reading order. ConvertVault normalizes Unicode, soft hyphenation, line endings, repeated spaces, paragraphs, and table separators while preserving source wording. It does not silently invent or rewrite uncertain words. Important extracted text should be reviewed against the source.

PDF-to-DOCX is not currently exposed; any future implementation will be best-effort because PDF does not contain DOCX editing structure. Office fidelity depends on installed fonts; layouts, SmartArt, embedded objects, formulas, presentation effects, and uncommon features may change. Macros are never executed. Pandoc and Office PDF output depend on installed renderers. HEIC HDR may tone-map when written to 8-bit formats. Lossy compression reduces visual quality, password-protected files require the correct password, and compression savings vary with prior optimization.
